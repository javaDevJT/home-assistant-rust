# Unicode decimal data

`unicode16-decimal-zeroes.txt` contains the 76 decimal-digit block starts from
Unicode 16.0.0 `UnicodeData.txt`, matching CPython 3.14.2's decimal categories.
It is reused unchanged from the audited Application Credentials slug data;
its SHA-256 is `4822e3ebfa172bb896f9cbed8a88b026b4338b3213f2c7ab69bae3fff11163ce`.
Source: https://www.unicode.org/Public/16.0.0/ucd/UnicodeData.txt . The complete
Unicode license is retained in `unicode-license.txt`.
